# Stock Price Prediction using Machine Learning

Proyek analisis data dan pemodelan prediktif berbasis *Machine Learning* untuk peramalan harga saham (*time-series forecasting*) menggunakan data historis pasar modal.

---

## 📌 Gambaran Proyek

Proyek ini bertujuan untuk menganalisis tren pergerakan harga saham dan membangun model prediksi harga penutupan (*Close price*) menggunakan algoritma pembelajaran mesin untuk mengevaluasi akurasi peramalan pada data deret waktu keuangan.

---

## 🛠️ Tech Stack & Library

- **Bahasa**: Python 3
- **Platform**: Google Colab / Jupyter Notebook
- **Library Utama**:
  - `pandas` & `numpy` — Pembersihan, manipulasi, dan kalkulasi array data.
  - `matplotlib` & `seaborn` — Visualisasi tren data dan evaluasi grafik.
  - `scikit-learn` — Preprocessing data, split train-test, dan evaluasi metrik (MAE, RMSE, R²).
  - `xgboost` — Model gradient boosting untuk prediksi deret waktu.
